# Code of Conduct

## The short version

Be decent. Assume good faith. Argue about the code, never about the person.

## What we expect

- Give feedback on the work, with a reason attached.
- Accept feedback the same way. A rejected patch is not a rejected person.
- Respect that maintainers have limited time and may say no.
- Keep it in English or Bahasa Indonesia, whichever the thread already uses.

## What is not acceptable

- Harassment, insults, or personal attacks of any kind.
- Sexual language or imagery.
- Publishing another person's private information.
- Repeatedly pushing a change after a maintainer has declined it.

## Reporting

Report a problem privately to the maintainer through the address in
[`SECURITY.md`](SECURITY.md). Reports stay confidential. The maintainer can
edit, hide, or remove any contribution, and can block an account, when this
document is broken.

This document is adapted from the Contributor Covenant, version 2.1.
